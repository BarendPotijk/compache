Assumptions
  • Token counts and list prices. No model is called, and answer quality is not measured.
  • The policy has the package's form: how many turns of questions, answers and retrieved text stay, and how many pings. Before each request and after each answer it looks three turns ahead, as the package does. The cheapest candidate on one set of threads wins. Costs come from a second set.
  • A needed part that Compache archived costs one extra call. A comparison that drops text for good does not pay for it and does not have it: that is the “missing” column. Text that is in a summary counts as missing.
  • Comparisons follow documented defaults, read on the date in each tooltip, and are not run. OpenAI's own compaction has no documented default and is not modeled.
  • A cache entry needs an identical start of the request and lives exactly its lifetime from when the request was sent.
  • The range beside the saving draws the sampled threads again. It does not cover what the model leaves out.
