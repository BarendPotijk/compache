Assumptions
  • Synthetic token-block estimates; no models are called and answer quality is unmeasured.
  • One answer call per run, with zero request duration and no extra recovery or retry calls. Recalled input is charged.
  • Earlier inputs and outputs stay intact; only retrieval history is compacted. Current dependencies are identified correctly.
  • Cache reuse requires an unchanged prefix. Cross-thread reuse, routing misses and early eviction are excluded.
  • The lowest-cost feasible policy is selected from a finite grid on this scenario; it is not a global optimum.
  • OpenClaw uses client-side summaries at 75% context with a 20k recent tail. Native compaction and provider-specific tool pruning are excluded.
