Assumptions
  • Token counts and list prices. No model is called, and answer quality is not measured.
  • One answer call per turn. A needed source that was archived or cleared costs one extra call, on both sides. A source OpenClaw summarized is not fetched again.
  • Both sides know which earlier sources a turn needs.
  • Compache archives only old retrieved text. Its policy is the cheapest candidate on one set of threads. Costs come from a second set.
  • OpenClaw follows its documented defaults and sends no keep-warm requests. Claude: tool results are cleared above 30% of the window, keeping the newest three. OpenAI: older turns are summarized at 75%. Its default there, OpenAI's own compaction, is not modeled.
  • A cache entry needs an identical start of the request and lives exactly the provider's default lifetime.
