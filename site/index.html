Assumptions & sources

One company, one parameter set. Planned thread length and the chance of continuing jointly determine survival. Dependencies are assumed identified correctly. Source availability does not establish answer quality.

Compache and OpenClaw are modeled as token blocks. OpenClaw uses the pinned client-summary path: 75% maintenance threshold, 20k recent tail and bounded summary input. Extra recovery calls are zero; recalled tokens and maintenance calls are charged. Cache windows are scenarios, not provider guarantees.
